# نمونه آزمایشی مدیریت اسناد NEAL Pharmed

این پوشه یک نمونه مستقل و نمایشی است؛ به دیتابیس، ورود کاربران، ONLYOFFICE یا سرویس ذخیره‌سازی متصل نیست. فایل‌ها/پوشه‌ها/مجوزهایی که در مرورگر اضافه می‌شوند موقتی‌اند و با refresh از بین می‌روند. فایل واقعی آپلود یا ذخیره نمی‌شود.

## اجرا
فایل `index.html` را از GitHub دانلود کنید و در مرورگر باز کنید. برای نمایش فونت Vazirmatn در این نسخه، اینترنت لازم است؛ در نسخه عملیاتی از فونت‌های محلی پرتال استفاده خواهیم کرد.

## قابلیت‌های نمایشی
- فضای شخصی + پوشه‌های مشترک شرکت
- ساخت پوشه و شبیه‌سازی انتخاب چند فایل
- پنل نمونه مجوزهای کاربر: مشاهده، دانلود، آپلود، ویرایش، حذف
- فهرست فعالیت‌های نمایشی

## وضعیت
این بسته فقط برای بررسی ظاهر و گردش‌کار است؛ اتصال ONLYOFFICE و کنترل امنیتی سمت سرور هنوز پیاده‌سازی نشده است. آن را در مسیر فعال پرتال کپی نکنید و با فایل‌های محرمانه آزمایش نکنید.

## بررسی دیتابیس
طبق schema ارسال‌شده در گفتگو، جدول‌های users و admins وجود دارند؛ همچنین useful_files و chat_attachments کاربردهای فعلی خود را دارند. در schema ارائه‌شده جدول‌های مخصوص پوشه‌های اسناد، ACL دسترسی اسناد یا audit اختصاصی دیده نشد. هیچ migration یا SQL در این بسته وجود ندارد.
